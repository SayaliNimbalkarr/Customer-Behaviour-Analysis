# Customer Shopping Behaviour Analysis

## Overview

This project analyzes customer shopping behaviour using Python, PostgreSQL, and Power BI. The goal was to explore customer purchasing patterns, clean and prepare the data, perform SQL-based analysis, and create an interactive dashboard for business insights.

## Dataset

The dataset contains customer shopping transaction data, including customer demographics, product information, purchase details, payment methods, shipping preferences, and customer engagement metrics. The data was used to analyze purchasing patterns and generate business insights.

## Tools Used

* **Python** – Data loading, cleaning, and exploratory data analysis (EDA)
* **Pandas & NumPy** – Data manipulation and preprocessing
* **PostgreSQL** – SQL querying and analysis
* **Power BI** – Dashboard creation and reporting

## Project Steps

### 1. Data Loading

* Imported the dataset into Python.
* Examined the structure and basic information of the data.

### 2. Exploratory Data Analysis (EDA)

* Analyzed customer purchasing trends.
* Explored distributions, patterns, and relationships between variables.
* Created visualizations to better understand the data.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicates where necessary.
* Standardized and prepared data for analysis.

### 4. SQL Analysis

* Imported the cleaned dataset into PostgreSQL.
* Wrote SQL queries to answer business-related questions.
* Generated insights on customer behaviour, sales, discounts, and purchasing patterns.

### 5. Dashboard Development

* Connected the processed data to Power BI.
* Built an interactive dashboard to visualize key metrics and trends.
* Added filters and charts for easier analysis.

## Dashboard Highlights

The Power BI dashboard provides insights into:

- Average Purchase Amount
- Average Review Rating
- Customer Subscription Status
- Revenue by Product Category
- Sales by Category
- Revenue by Age Group
- Top-Selling Products
- Sales by Shipping Type

Interactive filters allow users to explore data by subscription status, gender, and product category.

## Results

The analysis provided insights into:

* Customer purchasing behaviour
* Popular product categories
* Revenue trends
* Impact of discounts on purchases
* Preferred payment and shipping methods

## How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Run the Jupyter Notebook or Python scripts for data cleaning and EDA.
4. Import the cleaned dataset into PostgreSQL.
5. Execute the SQL queries provided in the project.
6. Open the Power BI file to explore the dashboard.

## Conclusion

This project demonstrates a complete data analysis workflow, from data preparation and SQL analysis to dashboard creation. It highlights how data can be transformed into meaningful business insights through analytics and visualization.
